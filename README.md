# Sales & Operations Analytics

An in-progress analytics project using Microsoft's AdventureWorks sample database to practice the end-to-end analyst workflow: understanding a relational database, validating data, answering business questions with SQL, and communicating findings.

## Current status

The project is in the database exploration phase. The current work is identifying tables, columns, keys, and relationships before choosing focused business questions.

## Tools

- Microsoft SQL Server and T-SQL
- SQL Server Management Studio
- Git and GitHub

AdventureWorks is Microsoft sample data, not current data from a real company. Analysis and findings will be added after the data has been explored and validated.
